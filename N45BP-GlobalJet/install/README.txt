N45BP livery for the iniBuilds Global Jet (MSFS 2024)

1. Close MSFS 2024.
2. Double-click INSTALL-N45BP.bat (if Windows warns, choose More info > Run anyway).
3. Start MSFS 2024, pick the Global Jet, Configure, livery "N45BP (camo)".

The installer finds your Community folder and any Global Jet livery you already have,
learns the real aircraft folder and texture names from it, and installs the livery.
It only adds or removes packages whose name starts with "n45bp".
Best result: have at least one Global Jet livery installed (any free one from iniManager)
before running it. If the livery is missing or not camo, paste N45BP-install-report.txt to Claude.
